# Steam Frame Helper

Набор твиков и утилит для **Steam Frame** (SteamOS, aarch64) с графическим окном на GTK3. Каждая функция включается и выключается одной кнопкой, а приложение пишет, что именно меняется в системе.

Полная документация: **[docs/GUIDE.ru.md](docs/GUIDE.ru.md)** (каждая вкладка, раздел и кнопка).

## Возможности

Разделы во вкладках сворачиваются, состояние запоминается. Переключатель языка (Русский / English) находится в заголовке окна, а внизу окна строка состояния показывает, что сейчас делает приложение.

- **Инструменты**
  - регион Wi-Fi (сохраняется после перезагрузки), Wi-Fi без энергосбережения
  - **статистика соединения с ПК (в шлеме)**: маленькое окно в шлеме с данными стрима в реальном времени: пинг и потери по данным самого Steam, трафик, сигнал и скорость связи адаптера Steam и домашнего Wi-Fi
  - запись в системный раздел (Разблокировать / Заблокировать), перезапуск Steam, перезагрузка
- **Плагины**: **Decky Loader** для ARM64 и управление плагинами Decky. В комплекте плагин *SFH Frame Menu*: Decky в левом меню Frame и в быстрых настройках, переключатель статистики соединения, кнопки выключения левого, правого или обоих контроллеров
- **Игры** и **Приложения**: бэкапы сохранений, очистка шейдеров и префикса для игр Steam; Flatpak-приложения из Flathub
- **Android**: установка APK (+ OBB) как VR-приложения в библиотеку Steam через Lepton
- **Передача**: копирование скриншотов на Frame и на ПК, отправка файлов с Frame на ПК
- **Разработка**: интерфейс Steam в браузере на ПК, Wi-Fi без запроса пароля в RDP-сессии

## Установка на Steam Frame

В режиме рабочего стола откройте Konsole (или зайдите по SSH) и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/SantaClousG-G/steam-frame-helper/main/install.sh | bash
```

Приложение появится в меню приложений как **Steam Frame Helper**. Повторный запуск той же команды обновляет его (локальные настройки и файлы сохраняются). Удаление: `bash install.sh --uninstall` (твики системы остаются как были).

У пользователя `steamos` по умолчанию нет пароля. Функции, меняющие систему, требуют root: приложение пробует `sudo` без пароля, затем системное окно пароля (`pkexec`). Задайте пароль один раз командой `passwd` в Konsole.

## Часть для ПК (Windows 10/11)

Нужна для копирования скриншотов на ПК, приёма файлов с Frame и ярлыка «Отправить на Frame» на рабочем столе. На Frame задайте пароль (`passwd`) и включите SSH: `sudo systemctl enable --now sshd`.

Скачайте архив релиза, распакуйте и выполните в PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File steam_frame_helper\pc\install.ps1
```

Установщик спросит адрес Frame (`пользователь@IP`, например `steamos@192.168.0.50`), настроит вход по SSH-ключу (пароль Frame спросит один раз) и поставит скрытого агента на ПК и ярлык. Подробности в [руководстве](docs/GUIDE.ru.md#часть-для-пк).
